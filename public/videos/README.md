# Public treatment videos

Upload short, optimized, silent treatment animation loops here.

Suggested names:
- `hair-growth-loop.webm` and `hair-growth-loop.mp4`
- `hair-growth-poster.jpg`
- `sexual-health-loop.webm` and `sexual-health-loop.mp4`
- `sexual-health-poster.jpg`

Files placed in this directory are served by Next.js under `/videos/<filename>`.

The current homepage animation is at `/images/floating_medicines.mp4`; it is intentionally left unchanged until the other animation assets are reviewed and integrated.
